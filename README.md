# Telegram-бот для записи

Демо Axon: Telegram-бот для записи на услуги, управления расписанием и автоматических напоминаний.

> Демонстрационный проект портфолио Axon. Статус: планирование. В репозитории пока только описание; перечисленные возможности предстоит реализовать.

## Задача

Автоматизировать запись клиентов студии услуг и работу администратора.

## Возможности MVP

- Выбор услуги, специалиста, даты и свободного времени.
- Подтверждение, перенос и отмена записи.
- Напоминания клиенту и уведомления администратору.
- Панель управления услугами, специалистами и расписанием.
- Защита от двойного бронирования и учёт часового пояса.

## Демонстрационный сценарий

Клиент записывается в Telegram, получает подтверждение и переносит визит; администратор видит обновлённое расписание.

## Критерии готовности

Один слот нельзя забронировать дважды. Перенос освобождает прежнее время. Отменённые записи не вызывают напоминаний.

- Работает демо с синтетическими данными и понятным входом.
- Основной сценарий проверен; запуск и переменные окружения документированы без секретов.
- Подготовлены скриншоты, короткое видео и кейс для сайта Axon.
- Проект обозначен как демонстрационный, без вымышленных клиентов и результатов.

## Границы первой версии

Одна компания; без предоплаты и внешних календарей.

## Какие услуги демонстрирует

Telegram-боты, автоматизация, фоновые задачи, административные панели.

## Этапы реализации

1. Уточнить сценарии, модель данных и интерфейсы; выбрать стек.
2. Реализовать основной пользовательский путь и управление данными.
3. Добавить интеграции, валидацию, обработку ошибок и проверки доступа.
4. Проверить критерии готовности, наполнить демо и подготовить материалы портфолио.

Стек, команды запуска и ссылка на демо будут добавлены по мере реализации.
