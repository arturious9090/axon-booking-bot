# Axon Admin · рабочее расписание

Mode: Operate. Scope: обновление существующего Django Admin, включая главную,
навигацию, списки, формы и подтверждение отмены. Пользователь выбрал недельный
календарь по специалистам и сохранение Django Admin вместо отдельного приложения.

## Direction contract

THESIS: рабочая неделя команды видна сразу; на первом экране находятся реальные
записи и интервалы работы, а не декоративная аналитика.

OWN-WORLD: сдержанная светлая рабочая среда Axon, зелёный акцент для действий
и выделения, белые формы и таблицы на светлом нейтральном фоне. Один системный
шрифт, тонкие границы, простые подписанные элементы управления, единые SVG-иконки.

STORY: администратор выбирает неделю и специалиста, видит визит, открывает
его подробности и при необходимости отменяет с подтверждением. Услуги, команда
и отсутствие доступны из постоянной навигации с учётом прав пользователя.

FIRST VIEWPORT: слева рабочие разделы, сверху учётная запись; в содержимом
заголовок, выбор недели и фильтры, затем таблица с днями по горизонтали
и специалистами по строкам. На узком экране неделя становится повесткой по дням.

FORM: расширение существующей поверхности Django Admin по точно заданному
пользователем сценарию. Концептуальная жеребьёвка не применялась: композиция
«недельный календарь по специалистам» выбрана пользователем напрямую.
Build path: code; без утверждённого изображения-макета и растровых материалов.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Ограничения: сохранить данные и рабочие формы Django, авторизацию и CSRF;
не добавлять вымышленные записи и показатели. Проверить desktop, mobile,
доступ к данным по разрешениям, фильтрацию и отмену. Стиль спокойный и понятный,
без декоративной анимации и без изменения клиентской страницы.
